NovaCode

A block editor for big Scratch projects.

More blocks and tools for Scratch.

Functions that return values, arrays and dicts, a debugger, tabs and split view. Exports a vanilla .sb3 that runs on scratch.mit.edu.

What's in it

More blocks

Functions that return, recursion, arrays, dicts and sets, vectors and quaternions, for-each loops, switch, and dozens of new operators.

Editor tools

Tabs and split view, script files and folders, a minimap, bookmarks, a debugger with breakpoints, and project stats.

Art, sound and camera

A camera, pen printing, a pixel and vector editor, sound tools, and built-in asset libraries.

Runs on Scratch

Every project exports as a vanilla .sb3 that runs on scratch.mit.edu: no special extensions, no modified player.

Feature overview

Features

Everything NovaCode adds to Scratch, by section. Every block is explained in the .

CompatibilityExports to vanilla Scratch

Advanced code, vanilla Scratch

Write with everything NovaCode has, then export a vanilla .sb3. It runs on scratch.mit.edu: no special extensions, no modified player.

Open your Scratch projects

Open any .sb3 and keep working on it with NovaCode’s editor and blocks.

Builds

Compile your project into a build to run, check and download. Every export is kept, so you can go back to an older one.

ProgrammingBlocks Scratch doesn’t have

Functions that return a value

Custom blocks can give back a number, text or true/false, and go straight into other blocks.

Recursion and warp

Functions can call themselves, and can run without screen refresh.

Scopes

Functions for one file or for every actor. Variables just for one script, one file, one actor, or everyone, sorted that way in the palette.

More loops

for, and for-each over lists, arrays, dicts, sets, letters and words. Break and continue.

switch and else if

switch / case, if … else if, and wait or until.

Arrays, dicts and sets

Real data structures (S3ON), nested any way you like.

List tools

Sort, search, count and more, without building them from scratch each time.

Math+

Clamp, lerp, map, wrap, noise, seeded random, easing, bit operations and more.

Strings+

Split into words, search and replace, pad, capitalize, and dozens more text blocks.

Vectors and quaternions

2D and 3D vectors and quaternions, each with their own block shape.

Camera

Move, zoom, turn and shake a camera, follow a sprite, add parallax.

Pen printing

Draw text on the stage with the pen, in any size and colour.

Actors and clones

Tell another actor to do something, make a clone at a spot, count clones, and give clones IDs.

Debug blocks

Log, warn, assert, time things, pause on a breakpoint, and type debug commands while it runs.

WorkspaceOrganise big projects

Tabs

Keep scripts, sprites and sounds open in tabs, like a code editor.

Split view

Two code areas side by side. Drag scripts across, even between actors.

Script files and folders

Split an actor’s code into files and folders instead of one huge canvas.

Content drawer

Every actor, script, sprite and sound in one place: a folder tree and tiles.

Drag and drop

Drag things between the tree, tiles, folders and path bar. If a name’s taken, merge folders or keep both.

Cut, copy and paste

Right-click or ⌘X, ⌘C, ⌘V. Cut things fade until they’re pasted.

Safe moves between actors

A script moved to another actor brings its variables over as that actor’s own, and the functions it calls.

Project parts

Export an actor, a script or a whole folder as a .novapart file, and import it into another project.

EditingFind and edit code

Find

Search one actor or all of them, by name, comment title, or unused code.

Go to definition, find uses

Jump from a call to its function, or see every place a variable or function is used.

Outline

Every script in a file, in sections. Drag to reorder them.

Minimap, bookmarks and breadcrumbs

See the whole canvas at a glance, save places, and always know where you are.

Add block search

Type what you want (⇧⌘F) and drop it in.

Pinned blocks

Keep the blocks you use most at the top of the palette.

Multi-select

Pick several scripts and move, copy or tidy them together, with a handle in the middle.

Comment titles and checklists

Titles, checklists and formatting, with who wrote them and when.

Clean up and panning

Clean up into columns, smooth panning, and scrolling at the edges while you drag.

DevelopmentRun, debug and back up

Run any block

Click a block to run it and see its value, even straight from the palette.

Debugger

Breakpoints and a console, built into the editor.

Mini player and Player tab

Watch your project while you edit, or give it a whole tab. Dock the mini player in any corner.

Autosave and snapshots

Your work is kept in the browser as you go. Snapshots let you go back, and compare what changed.

Project stats

What your project uses, and how much: a skills score that counts loops and function calls.

Backpacks

Keep scripts, actors, sprites and sounds to reuse: one for this project and one for all of them.

CreativeArt, sound and themes

Costume editor

Pixel and vector art, with layers and gradients.

Sound editor

Trim, fade, change and record sounds.

Libraries

Built-in sprites and sounds to start from.

Themes, colours and block shapes

Pick a theme, accent colour and block shape.

Your own names for things

Call sprites “actors” (or something else), and put your name on your comments.

Web projects

Your projects, in the browser editor.
